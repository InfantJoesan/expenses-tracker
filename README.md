# 💸 Smart Expense Tracker

A simple, good-looking expense tracker that runs in the browser. No sign-up, no server.
Your data is saved in your own browser (localStorage).

## Features
- Add income and expenses with category, date and note
- Monthly balance, income and spending summary
- Budget bar with daily spending tips and month-end forecast
- Donut chart of spending by category
- Filter by category, export to CSV
- Works on phone and desktop, supports dark mode

## Put it online with GitHub Pages (free)
1. Create a new repository on GitHub, for example `smart-expense-tracker`.
2. Upload every file in this folder (keep the `css` and `js` folders). Click **Add file → Upload files**, drag the contents in, then **Commit changes**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`, choose branch `main` and folder `/ (root)`, then **Save**.
5. Wait about a minute. Your site will be live at:

   `https://YOUR-USERNAME.github.io/smart-expense-tracker/`

Tip: name the repository `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.

## Run locally
Double-click `index.html`.
